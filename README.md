# 💍 Бюджет свадьбы

Сайт для учёта бюджета сырға салу и свадьбы: план, итог по договору, авансы, оплаты и статус каждой затраты.
Открыть: https://bekbolatkuanyshev.github.io/wedding-budget/

## Возможности
- План и итоговая стоимость по каждой статье, перерасход или экономия
- Несколько платежей на статью (аванс, остаток…) с датой и комментарием, кнопка «Внести остаток»
- Статусы: «Запланировано», «Аванс внесён», «Закрыто»; фильтр и поиск
- Свои затраты и мероприятия, порядок мероприятий, удаление с отменой
- Вкладка «Подарки»: кто сколько подарил на сырға салу и свадьбу, подарки вещами
- Вкладка «Гости»: список гостей по мероприятиям, сколько человек, группа, стол, телефон (звонок и WhatsApp в одно касание), отметка «приглашение отправлено», ответ «придут / не придут» и сколько придут; итоги, фильтры, добавление списком, выгрузка в Excel
- Закрытая вкладка «Личное»: свои деньги, ожидаемые поступления, личные расходы, сколько не хватает и сколько откладывать в месяц. Шифруется паролем на устройстве (AES-GCM + PBKDF2), в облако уходит только шифр
  - «Зарплата»: доходы, обязательные и гибкие расходы, другие накопления (суммы в месяц, неделю или год), сколько остаётся и сколько откладывать на свадьбу
  - «Аналитика»: успеваете ли накопить к свадьбе, прогноз по месяцам, сценарий «сократить гибкие расходы», крупнейшие расходы, норма сбережений
- Синхронизация между телефонами через облако (Supabase): изменения сразу видны на всех телефонах
- Выгрузка в Excel (CSV) и резервная копия (JSON)

## Синхронизация между устройствами
Данные хранятся в Supabase (таблица `budgets`, миграция в `supabase/migrations`).
Весь бюджет — одна запись, доступ к ней только по секретному коду из ссылки:
публичный ключ в коде сайта напрямую к таблице доступа не даёт.

1. На одном телефоне: меню «⋯ → Синхронизация устройств» → «Создать облако».
   Данные из старой Google-таблицы и с телефона перенесутся автоматически.
2. На втором телефоне откройте ссылку или QR-код из того же окна.

Ссылку давайте только тем, кто ведёт бюджет: с ней можно видеть и менять данные.
Если таблица не создалась автоматически через интеграцию Supabase с GitHub,
выполните SQL из `supabase/migrations/` в Supabase → SQL Editor.

Старая синхронизация через Google-таблицу (`apps-script/Code.gs`) работает, пока облако не подключено.

## Публикация
Сайт публикуется на GitHub Pages автоматически (`.github/workflows/pages.yml`) при каждом изменении в ветке `main`.
