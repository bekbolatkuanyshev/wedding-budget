# 💍 Бюджет свадьбы

Одностраничный сайт для учёта бюджета свадьбы и сырға салу: план, факт, авансы, оплаты и статус каждой затраты.

## Возможности
- План и итоговая (фактическая) стоимость по каждой статье, отклонение от плана
- Несколько платежей на статью (аванс, остаток…) с датой и комментарием
- Статусы: «Запланировано», «Аванс внесён», «Закрыто»
- Добавление своих затрат и мероприятий, поиск и фильтр по статусу
- Экспорт/импорт JSON (перенос между устройствами) и выгрузка CSV для Excel

## Где хранятся данные
В браузере (localStorage). Чтобы открыть те же данные на другом устройстве — «Экспорт» на одном и «Импорт» на другом.

## Публикация на GitHub Pages
Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.
