# 💍 Бюджет свадьбы

Сайт для учёта бюджета сырға салу и свадьбы: план, итог по договору, авансы, оплаты и статус каждой затраты.
Открыть: https://bekbolatkuanyshev.github.io/wedding-budget/

## Возможности
- План и итоговая стоимость по каждой статье, перерасход или экономия
- Несколько платежей на статью (аванс, остаток…) с датой и комментарием, кнопка «Внести остаток»
- Статусы: «Запланировано», «Аванс внесён», «Закрыто»; фильтр и поиск
- Свои затраты и мероприятия, порядок мероприятий, удаление с отменой
- Синхронизация между телефонами через вашу Google-таблицу
- Выгрузка в Excel (CSV) и резервная копия (JSON)

## Синхронизация между устройствами
Данные хранятся в вашей Google-таблице через Apps Script (`apps-script/Code.gs`).
Настройка — в меню сайта «⋯ → Синхронизация устройств», там же пошаговая инструкция.
Кратко:
1. Создайте Google-таблицу → Расширения → Apps Script → вставьте код из `apps-script/Code.gs`.
2. Развернуть → Новое развертывание → Веб-приложение: выполнять от имени «Я», доступ «Все».
3. Вставьте URL веб-приложения на сайте. Для второго телефона отправьте ссылку из окна синхронизации.

Без подключения облака данные хранятся только в браузере устройства.
